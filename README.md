# 🧮 JavaScript Calculator

A modern calculator built from scratch using **HTML, CSS, and JavaScript**.

This project was created to practice JavaScript DOM manipulation, events, keyboard interactions, and building a complete interactive UI without relying on external libraries.

## ✨ Features

* Basic arithmetic operations
* Addition, subtraction, multiplication, and division
* Decimal numbers
* Parentheses
* Clear and Delete buttons
* Keyboard support
* Interactive button press effects
* Error handling for invalid calculations
* Responsive and clean UI

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript (ES6+)

## 🎯 What I Practiced

Through this project, I practiced:

* DOM Selection and Manipulation
* Event Listeners
* Keyboard Events
* Conditional Logic
* Functions and Variables
* Working with JavaScript state
* CSS Transitions and Effects
* Git & GitHub
